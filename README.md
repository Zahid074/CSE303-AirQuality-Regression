# Urban Air Pollutant Concentration Regression

CSE303 Course Project — East West University

## Dataset
UCI Air Quality Dataset: https://archive.ics.uci.edu/dataset/360/air+quality

## Methods
- OLS Multiple Linear Regression (baseline)
- Huber Regressor, RANSAC Regressor (robust regression)
- Sliding-Window Recursive Regression (drift-adaptive, novelty)
- Decision Tree, SVR (comparison baselines)

## Results
See `final_model_comparison.csv` for full metrics table.

## How to Run
1. Download `AirQualityUCI.csv` from the UCI link above
2. Open the notebook in Google Colab
3. Upload the CSV when prompted
4. Run cells sequentially
